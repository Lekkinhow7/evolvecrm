Line icon (Lucide, 1.5–2px stroke, rounded) that inherits text color — use for every UI glyph: nav, buttons, wells, table chevrons.

```jsx
<Icon name="activity" size={18} />
<Icon name="shield-check" color="var(--text-accent)" />
<Icon3D name="records-files" size={112} base="../../assets/icons-3d/" />
```

- Sizes: 16 (nav rows, inline), 18 (tiles, buttons), 20 (icon wells, topbar).
- Icon3D = the glass 3D illustration family; use in modal headers, empty states and hero cards, never inline with text.
- Common names: activity, square-check, atom, shield-check, chevrons-left, chevron-down, chevron-right, bell, log-out, sun, moon, building-2, search, refresh-cw, triangle-alert, package, users, lock, clock, calendar, layers, graduation-cap, id-card, file-text, shirt, x, plus.
